DocuMind AI 📄🤖

Seu assistente inteligente para leitura e resumo de documentos PDF.

O DocuMind AI é uma aplicação web que utiliza inteligência artificial para extrair informações e gerar resumos organizados de documentos PDF.

🌐 Acesse o projeto

"Experimentar o DocuMind AI" (https://radiant-fox-62a835.netlify.app)

🛠️ Tecnologias utilizadas

- Python
- FastAPI
- JavaScript
- HTML e CSS
- PyMuPDF
- Groq API
- Google Gemini API
- OpenRouter API

🚀 Status do projeto

Versão Beta — em fase de testes e melhorias.
